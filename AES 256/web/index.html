Comment ça marche
Chaque chiffrement génère un IV (vecteur d'initialisation) aléatoire de 16 octets, placé au début du résultat — c'est pour ça que chiffrer deux fois le même message donne deux résultats différents. Le mode CBC chaîne chaque bloc de 16 octets avec le précédent via un xor_bytes, avant de passer par encrypt_block. La clé ne sert qu'à toi : si tu la perds, le message chiffré n'est plus récupérable par personne.
